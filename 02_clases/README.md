# Clases

La numeración corresponde a la secuencia académica del curso. En cada módulo:

- `python/` contiene la ruta principal;
- `r_opcional/` contiene implementaciones o ejemplos alternativos;
- `ejemplos/` y `complementarios/` no son obligatorios;
- el `README.md` indica objetivos, datos y relación con el proyecto.

Los módulos 2, 12 y 13 conservan su lugar en el programa, pero requieren desarrollar o consolidar un notebook Python principal.
