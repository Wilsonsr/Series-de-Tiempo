# 02 — Exploración y visualización temporal

**Pregunta central:** ¿qué estructura tiene la serie y qué podría cambiar el pronóstico?

## Objetivos

- visualizar tendencia, estacionalidad, ciclos y cambios estructurales;
- estudiar calendarios, valores atípicos y periodos faltantes;
- diferenciar anomalía, ruido y evento explicable.

## Estado del material

Se debe crear un notebook Python principal a partir de las secciones exploratorias del módulo 1 y de los casos existentes. No se fuerza una implementación R independiente.

## Actividad

Construir un informe exploratorio con cinco visualizaciones y una hipótesis temporal verificable.

## Proyecto

Entregar la exploración inicial y justificar la frecuencia de análisis.
