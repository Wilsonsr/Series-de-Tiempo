# Datos del curso

Los datasets están organizados según el módulo donde se utilizan principalmente. `compartidos/` contiene series usadas en varias semanas.

| Carpeta | Uso principal |
|---|---|
| `01_fundamentos/` | Introducción y casos de aplicación |
| `05_suavizamiento/` | ETS y estacionalidad |
| `06_estacionariedad/` | ACF, PACF, ARMA y mercado laboral |
| `08_sarima/` | Modelos estacionales |
| `09_sarimax/` | Variables externas y regresión dinámica |
| `10_prophet/` | Caso climático |
| `11_machine_learning/` | Feature engineering y Bike Sharing |
| `13_multiples_series/` | Múltiples mercados y futura jerarquía |
| `14_var/` | Sistemas multivariados |
| `15_avanzados/` | Deep learning, VECM y extensiones |
| `clima/` | Fuentes climáticas adicionales |
| `compartidos/` | Café, gas e IPC |

Los archivos preservados por posible duplicación están en `../99_revision_manual/duplicados/` y no deben utilizarse como fuente oficial.
