# Instrucciones generales

El proyecto debe contener:

1. definición del problema y usuario del pronóstico;
2. variable temporal, frecuencia y horizonte;
3. origen, licencia y diccionario de los datos;
4. análisis exploratorio temporal;
5. preparación y control de calidad;
6. baseline;
7. al menos dos modelos candidatos;
8. estrategia de train/test y backtesting;
9. métricas apropiadas;
10. comparación homogénea;
11. diagnóstico de residuales y errores;
12. pronóstico final;
13. cuantificación de incertidumbre;
14. interpretación contextual;
15. conclusiones, limitaciones y recomendaciones.

## Formato

- notebook o proyecto reproducible en Python;
- datos o instrucciones verificables para obtenerlos;
- informe ejecutivo;
- presentación final;
- archivo de dependencias cuando el proyecto utilice librerías adicionales.
